## Проверка Bonsai 2 27B PTQ1_0 и vision

После отдельного явного разрешения на тяжёлый тест Bonsai 2 27B PTQ1_0 проверена на том же Apple M3 Pro с 18 GB RAM:

- Q8 vision projector размером 629246976 байт скачан через интерфейс приложения; SHA-256 `6807ede61d570bb86ba34b756a0fa109edc33668604de867c6ea6d8f1d631903` совпал с каталогом;
- использованы PrismML runtime `prism-b10709-9a9394a`, Metal, контекст 4096 и projector через `--mmproj`;
- холодный запуск до `/health: ok` занял примерно 15 секунд;
- во время загрузки наблюдаемый RSS `llama-server` достигал примерно 4,55 GB, после запуска держался около 3,7–4,1 GB. Это не включает всю Metal/shared-memory нагрузку, поэтому основным сигналом оставался системный memory pressure;
- минимальный показанный `memory_pressure -Q` запас составлял 15%, во время vision-запроса держался на 15–17%; система и приложение оставались отзывчивыми;
- текстовый запрос вернул «Бонсай»: 76 completion-токенов за 9,73 секунды, 7,71 токена/с. При лимите 24 токена модель потратила весь бюджет на `reasoning_content` и вернула пустой `content`, поэтому OpenAI-совместимому клиенту нужен достаточный лимит генерации;
- vision-запрос через интерфейс с `src/assets/app-icon.png` завершился успешно: модель распознала тёмно-зелёный фон, белый росток и буквы в листьях. Верхнюю букву `Z` она ошибочно прочитала как `A`, то есть pipeline работает, но точность OCR не гарантирована;
- штатная остановка завершила `llama-server`, освободила порт 8080 и подняла системный запас памяти с 15–20% до 69%.

Итог: PTQ1_0 с контекстом 4K фактически запускается и выполняет text/vision inference на этой конфигурации с 18 GB RAM. Это единичное измерение, а не гарантия совместимости: запас памяти небольшой, фоновые приложения и другие M-series конфигурации могут изменить результат. Продуктовую рекомендацию 24 GB пока сохраняем консервативной до повторных измерений.

При нативной автоматизации выбирать приложение по полному пути: выбор по имени может открыть старую версию из Applications.

## Незавершённые проверки и выпуск

Полный E2E вложений, vision, веб-поиска и восстановления непустой истории в финальном DMG ещё не подтверждён. Наличие реализации не заменяет эти проверки. При нативной автоматизации выбирать приложение по полному пути: выбор по имени может открыть старую версию из Applications.

Apple notarization заблокирована отсутствием Keychain-профиля `GZB-notary`; повторная проверка `xcrun notarytool history --keychain-profile GZB-notary` подтверждает отсутствие. Пользователь должен сохранить действительные credentials через `xcrun notarytool store-credentials GZB-notary`. Секреты не передавать в чат и не коммитить.

Далее: завершить указанный E2E, отправить DMG в notarytool, дождаться Accepted, выполнить staple/validate и Gatekeeper, обновить хэш, README и опубликовать v0.3.0. Публичная стабильная версия пока 0.2.0. Не объявлять всю задачу завершённой до этих шагов.

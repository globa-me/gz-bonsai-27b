# Нативная проверка 0.6.3

Дата: 24 сентября 2026 года. Устройство: Apple M3 Pro, 18 ГБ unified memory, macOS 26.5.

## Проверено

- Официальные карточки PrismML и Qwen на Hugging Face сверены для всех шести GGUF в каталоге. У 1.7B/4B/8B подтверждена архитектура Qwen3 соответствующего размера, у Bonsai 27B указана исходная Qwen3.6-27B, у обоих вариантов Bonsai 2 27B — Qwen3.8-27B. Ссылки в приложении ведут на конкретные карточки, а ссылка Bonsai соответствует репозиторию файла загрузки.
- `npm test`: 27/27; `cargo test --locked`: 22/22; `npm run build` и `npm run tauri -- build` успешны. Проверка каталога в Rust подтверждает соответствие URL карточки Bonsai URL загрузки и имени Qwen URL её карточки.
- Браузерный макет проверен на обычной ширине в RU/EN. Строка происхождения остаётся второстепенной по визуальному весу, а ссылки отделены от кнопок загрузки.
- Arm64 app bundle и все 36 Mach-O файлов встроенного runtime прошли проверку подписи. DMG прошёл `hdiutil verify`, Apple Notary Service (submission `c8f58ed0-d7cd-4c91-a571-f2c4f749316b`, Accepted), `stapler validate` и Gatekeeper `spctl` (`source=Notarized Developer ID`). Размер финального DMG: 30 558 565 байт; SHA-256: `e605bb2a1f49b521523a7489468e6b403ea52a99359b3389c80ea8b58b930efa`.
- Версия `0.6.3` установлена в `/Applications/GZ Bonsai 27B.app`; `Info.plist`, подпись и Gatekeeper проверены после копирования. История чатов сохранилась. Копия `0.6.2` находится в `~/Library/Application Support/GZ Bonsai Backups/GZ Bonsai 27B 0.6.2.app`.
- В установленном приложении верхнее меню выбора показало Qwen3-1.7B и Qwen3.8-27B для двух имеющихся моделей. Ссылки Bonsai и Qwen доступны как отдельные элементы, кнопки запуска остались самостоятельными. Быстрый старт для выбранной Bonsai 2 27B и полный каталог из шести вариантов показали правильные названия Qwen и ссылки.

## Границы

В `0.6.3` изменены только метаданные каталога и их отображение. Загрузка весов и генерация ответа повторно не выполнялись: эти пути проверены в предыдущих релизах, а их код и URL не менялись. Браузерный preview содержит копию метаданных каталога; при следующем изменении моделей его нужно обновить вместе с Rust-каталогом.

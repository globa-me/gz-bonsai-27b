# Сквозная проверка 0.2.0

Дата: 21 сентября 2026 года.

## Окружение

- Apple M3 Pro, 18 ГБ unified memory;
- macOS 26.5, arm64;
- собранный `GZ Bonsai 27B.app` с ресурсами из `Contents/Resources/runtime`;
- чистый управляемый каталог моделей перед началом проверки.

## Проверенный путь

1. Приложение определило чип, память, macOS и свободное место.
2. На момент E2E каталог показал четыре варианта и рекомендовал 8B для 18 ГБ как консервативную эвристику. Перед релизом каталог расширен отдельными 1-bit и ternary 27B вариантами; их полная загрузка этим тестом не покрыта.
3. Bonsai 1.7B Q1_0 скачан из интерфейса без Terminal.
4. Размер и SHA-256 проверены; `.part` атомарно превращён в готовый GGUF и появился как выбранная модель.
5. Встроенный Developer ID‑подписанный runtime запущен с `127.0.0.1`, Metal и контекстом 4096.
6. Health check перешёл в состояние «Модель готова».
7. Запрос «Ответь одним словом: работает?» получил потоковый ответ «Да, работает.».
8. Runtime штатно остановлен из интерфейса.

Отдельно загрузка 4B была остановлена после 25 837 568 байт. Повторное нажатие «Продолжить» начало HTTP Range‑загрузку с сохранённой позиции; UI показал 5%. Тестовый `.part` после проверки удалён.

## Границы доказательства

Проверка доказывает полный пользовательский путь для 1.7B на указанном Mac и механизм resume для 4B. Она не доказывает производительность или пиковую память 4B/8B/27B на других машинах. RAM‑пороги в UI остаются явно помеченной оценкой.

## Финальный DMG

После добавления 1-bit/ternary вариантов и новой G/Z/B-иконки приложение пересобрано заново.

- файл: `GZ-Bonsai-27B-0.2.0-arm64.dmg`;
- Apple Notary Service: `Accepted`, submission `53ffba65-8de0-4a39-a22a-220ccaa0b9e9`;
- ticket stapled и проверен `xcrun stapler validate`;
- DMG и приложение приняты `spctl` как `Notarized Developer ID`;
- основной executable внутри DMG проверен как `arm64`;
- `codesign --verify --deep --strict` пройден;
- внутри runtime проверено 36 Mach-O файлов, невалидных подписей нет;
- приложение запущено непосредственно из смонтированного DMG; нативный каталог показал все шесть вариантов, включая `Bonsai 27B · 1-bit Q1_0`, `ternary PTQ1_0` и `ternary PQ2_0`.

Полная загрузка новых 27B-файлов не выполнялась: их pinned URL, commit, размер и LFS SHA-256 сверены через официальный Hugging Face API, а общий механизм download/resume/SHA-256 уже покрыт E2E для 1.7B и 4B.

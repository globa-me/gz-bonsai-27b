- `npm audit --omit=dev`: уязвимостей не найдено;

Rust-тесты отдельно проверяют финальный SSE-блок с точными `usage` и `timings`. Frontend-тесты проверяют ручное название чата и взвешенную по сгенерированным токенам среднюю скорость.

## Нативный E2E

Подписанный release app bundle открыт по полному пути, чтобы исключить случайный запуск старой версии из Applications. На установленной Bonsai 1.7B Q1_0 проверены:

- переименование существующего чата и восстановление исходного названия;
- реальный streaming-ответ со встроенным PrismML runtime `prism-b10709-9a9394a`;
- метрики ответа: 88 входных, 5 выходных и 93 общих токена, 156,3 токена/с, полное время 0,2 с;
- совпадение индивидуальных метрик ответа со сводкой текущего чата;
- сохранение ответа, метрик и сводки в IndexedDB после полного закрытия и повторного запуска приложения.

Удаление чата требует пользовательского подтверждения и поэтому не выполнялось над существующей локальной историей во время автоматизации. Переход к следующему чату и создание пустого чата при удалении последнего покрыты логикой приложения; операции с названием покрыты модульными тестами.

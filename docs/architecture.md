# Архитектура и состояние разработки

## Текущий вертикальный срез

```text
React UI
  │ Tauri invoke + events
Rust application core
  ├─ system diagnostics
  ├─ lifecycle state machine
  ├─ health polling
  └─ SSE client
       │ localhost only
PrismML llama-server
       │
GGUF model (+ optional mmproj)
```

Rust запускает выбранный executable с `--host 127.0.0.1`, проверяет порт, передаёт модель, контекст и Metal offload, затем ждёт успешный `/health`. stdout/stderr поступает в диагностический журнал. Чат отправляется из Rust, а SSE-токены возвращаются событием `chat-token`.

## Проверенные свойства

- сервер не получает `0.0.0.0` из UI или конфигурации;
- второй процесс не запускается поверх работающего;
- порт проверяется до `spawn`;
- ранний выход процесса переводит приложение в ошибку;
- health check ограничен 180 секундами, после timeout процесс завершается;
- при закрытии окна процесс получает kill;
- отчёт использует только имена файлов, а не полные пути;
- SSE разбирается после получения полной строки, а не произвольного сетевого chunk.

# GZ Bonsai 27B 0.6.6

## Изменения

- Каталог «Все модели» раскрыт по умолчанию и включает выбранную модель. После остановки сервера можно удалить любую установленную модель, включая единственную и последнюю, без скачивания другой. Кнопка «Остановить модель» теперь доступна сверху страницы моделей; при запущенном сервере каталог объясняет, почему удаление временно недоступно.
- Нативная проверка обнаружила, что `window.confirm` в Tauri не показывал подтверждение. Модель, чат и локальный RAG-документ теперь используют явный модальный диалог с фокусом на отмене, поддержкой Escape и блокировкой взаимодействия с фоном.
- Удаление требует подтверждения, очищает выбранные пути весов и vision projector, обновляет каталог и свободное место. История чатов и RAG-документы сохраняются.
- Во время удаления заблокированы запуск, переключение, установка и ручная настройка. Rust самостоятельно проверяет живой процесс и активные загрузки и удерживает блокировки до завершения удаления.
- При обновлении каталога очищаются пути исчезнувших управляемых файлов. Для определения принадлежности используется точный путь от Rust, а не название файла или предположение по суффиксу; внешние пользовательские GGUF сохраняются.
- Успешно скачанные веса остаются доступны для текстового чата, даже если загрузка vision projector приостановлена или завершилась ошибкой. При возобновлении projector интерфейс использует его собственный идентификатор загрузки.
- Некорректные сохранённые настройки и отказ localStorage больше не обрушивают интерфейс.
- Действия карточек переносятся на новую строку, если кнопки не помещаются.
- Добавлены тесты отрисованного интерфейса и проверки GitHub для следующих изменений.

## Как удалить все модели

1. Остановить модель (в чате: селектор модели → «Остановить модель»; на странице моделей: «Остановить модель» в блоке быстрого старта).
2. Открыть «Модели» → «Все модели».
3. На каждой установленной карточке нажать «Удалить» и подтвердить. Выбранная модель удаляется таким же способом; выбирать или скачивать замену не требуется.

Удаляются веса, файлы поддержки изображений, маркеры проверки и незавершённые загрузки соответствующей управляемой модели. Приложение, runtime, чаты, RAG и вручную подключённые внешние файлы сохраняются.

## Проверка

Команды, нативные сценарии и ограничения: [e2e-0.6.6.md](e2e-0.6.6.md). Автоматические UI-тесты используют mock Tauri IPC и событий; они не заменяют проверку подписанного приложения с настоящим runtime.

## Продолжение разработки

UI-тесты: `src/App.ui.test.tsx`; запуск: `npm test`. Vitest для остальных unit-тестов сохраняет Node-окружение; UI-файл использует jsdom. Безопасность удаления и временные файловые fixtures проверяются в `src-tauri/src/installer.rs`. Исходная ошибка воспроизведена отсутствием карточки выбранной модели и сохранённым несуществующим путём. Каталог и runtime не обновлены; официальные файлы повторно сверены, подробности в `verified-artifacts.md`.

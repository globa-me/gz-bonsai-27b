# Инструкции для AI-агентов

## Контекст

Это открытый проект настольного приложения для максимально простого локального запуска моделей Bonsai. Версия `0.2.0` реализована как Tauri 2 + React + TypeScript с Rust-бэкендом. Текущее состояние, проверенные возможности и ограничения описаны в `README.md`; архитектура, разработка, проверенные артефакты и smoke-тест находятся в `docs/`; визуальная система зафиксирована в `DESIGN.md`.

## Продуктовый приоритет

1. macOS на Apple Silicon.
2. Новичок устанавливает приложение и запускает рекомендованную модель без Terminal.
3. Загрузка, запуск, остановка и удаление должны быть надёжными и прозрачными.
4. Локальная приватность и понятный интерфейс важнее количества функций.
5. Endpoint, OpenCode, удалённый доступ и веб-поиск — полезные, но вторичные возможности.
6. Windows и Linux — после стабильного macOS MVP.

## Техническое направление

- Основа проекта: Tauri 2 + React + TypeScript, Rust для системных операций.
- Первый runtime: `llama-server`/`llama.cpp` с Metal и моделями GGUF.
- Не добавлять Python/MLX в основной установочный путь до отдельного подтверждения ценности прототипом.
- Не форкать Jan без нового обоснования: текущая рекомендация — компактная собственная оболочка.
- Большие веса модели никогда не коммитить в Git.
- Сетевой сервер по умолчанию слушает только `127.0.0.1`.

## Правила работы

- Перед изменениями читать актуальную официальную документацию PrismML и проверять, что названия моделей, URL, размеры и лицензии не изменились.
- Не выдавать оценки совместимости и требований к памяти за факт без измерений.
- Не копировать визуальный дизайн ChatGPT или Jan буквально; нужен самостоятельный чистый интерфейс.
- Все пользовательские строки сразу закладывать через локализацию RU/EN.
- Секреты в будущем хранить в Keychain; не писать их в логи или обычные конфиги.
- Загрузки должны поддерживать отмену, возобновление, проверку размера/хэша и безопасное удаление временного файла.
- Управление sidecar должно учитывать аварийное завершение, занятый порт, повторный запуск и восстановление после сна.
- Изменения проверять тестами в соответствии с риском.

Цель — чтобы другой агент мог продолжить разработку без восстановления истории чата.

## Текущее состояние и следующий шаг

- Релиз `0.2.0` включает подписанный PrismML runtime и каталог из шести файлов: 1.7B/4B/8B Q1_0, отдельную бинарную 1-bit Bonsai 27B и ternary Bonsai 2 27B в PTQ1_0/PQ2_0; URL, размер и SHA-256 закреплены.
- Основная иконка — зелёный квадрат с белым трёхлистным bonsai и буквами G/Z/B в листьях. Редактируемый источник: `src/assets/app-icon.svg`; перед релизом platform icons генерируются `npm run tauri -- icon src/assets/app-icon.svg`.
- Пауза, HTTP Range resume, отмена с очисткой `.part`, атомарная установка и удаление по известному model id реализованы в Rust.
- Полный нативный E2E проверен с Bonsai 1.7B Q1_0: скачивание, SHA-256, Metal, health и streaming chat. Пауза/resume отдельно проверены на загрузке 4B.
- RAM-пороги остаются продуктовой эвристикой, а не доказанной совместимостью; следующий этап — измерения 1-bit/ternary на нескольких M-series, vision и локальная история.

## Автоматическая проверка

- `npm test`: 52 теста, 11 файлов; из них 25 сценариев отрисованного интерфейса в `src/App.ui.test.tsx`, остальные 27 — существующие unit-тесты.
- `npm run test:ui`: отдельный запуск интерфейсных сценариев.
- `npm run build`: TypeScript и Vite успешно.
- `cargo test --locked --manifest-path src-tauri/Cargo.toml`: 25 тестов успешно, включая три новых теста удаления.
- `cargo fmt --check --manifest-path src-tauri/Cargo.toml` и `cargo clippy --locked --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`: успешно.
- `git diff --check`: успешно.

UI-тесты проверяют выбранную/последнюю модель, отмену и ошибку удаления, остановку с каталога, блокировку действий во время удаления/загрузки, исчезнувшие управляемые файлы и сохранность внешнего GGUF, install/pause/resume/cancel, отказ vision projector, переключение моделей, повреждённые настройки/localStorage, streaming/Stop/Retry, RU/EN, панели и навигацию, переименование/удаление чатов и подтверждение удаления RAG. Регрессия удаления другого чата во время streaming проверяет сохранность токенов, пришедших при открытом подтверждении.

Tauri IPC и события в UI-тестах замоканы. Эти тесты не подтверждают загрузку настоящей модели, файловые операции или поведение нативного WebKit; соответствующие проверки описаны ниже. Rust-тесты работают с временными файлами, проверяют удаление только каталога известной модели, сохранность соседних файлов и отказ при symlink, работающем сервере и загрузке весов/projector.

`.github/workflows/checks.yml` запускает TS/UI, build, Rust tests, fmt и clippy на macOS при push в main и pull request. Проверка CI и опубликованные артефакты доступны на GitHub; при продолжении разработки смотреть статус текущего commit.

## Нативные сценарии в отдельном тестовом приложении

1. Реальная Bonsai 1.7B Q1_0 скачана через интерфейс. Пауза и возобновление работают, размер 248302272 bytes и SHA-256 проверены установщиком.
2. Модель запущена на Metal; `/health` возвращает 200. На запрос «Ответь одним словом: тест» получен streaming-ответ «Тест». UI показал 20 входных и 3 выходных токена. Это проверка работоспособности, не сравнительный benchmark.
3. На странице моделей удаление недоступно во время работы, кнопка «Остановить модель» останавливает сервер, после этого удаление доступно.
4. Карточка выбранной PTQ1_0 видна и доступна для удаления. Для этого сценария использован собственный sparse fixture ожидаемого размера с тестовым маркером. Он никогда не запускался как модель и не доказывает inference PTQ1_0.
5. Проверка обнаружила, что `window.confirm` в Tauri не выводил диалог. После замены на HTML `dialog.showModal()` подтверждение нативно показано на RU и EN, начальный фокус на «Отменить», отмена сохраняет веса.
6. Подтверждено удаление единственной выбранной реальной 1.7B. Каталог модели удалён, селектор очищен, чат и ответ остались. Для удаления последней модели не нужна замена.
7. Скрытие/восстановление боковой панели, карточки каталога RU/EN проверены визуально. Действия карточек допускают перенос строк.
8. Подтверждение удаления чата появляется, Escape отменяет операцию и сохраняет чат.
9. Собственный TXT импортирован через нативный выбор файла в локальный RAG. Отмена удаления сохраняет индекс. Подтверждение удаляет JSON индекса и связь с чатом; исходный TXT и существующий ответ сохраняются.

## Ограничения и продолжение

- В этой проверке не выполнялся inference настоящих 27B, повторная полная загрузка всех шести вариантов или vision inference. RAM-пороги остаются эвристикой.
- Windows/Linux и несколько размеров нативного окна не проверялись. jsdom не измеряет layout и не заменяет WebKit smoke.
- Массового удаления одной кнопкой нет: после остановки каждая установленная модель удаляется из «Все модели» с подтверждением. Внешний вручную выбранный GGUF управляется владельцем файла через Finder.
- Следующий шаг по runtime/совместимости остаётся прежним: измерения 1-bit/ternary на нескольких M-series и проверка vision остальных 27B-вариантов.
- Для продолжения UI-разработки: `npm ci`, `npm test`, `npm run build`; нативный smoke повторять в отдельном bundle id и тестовой библиотеке. Не использовать `window.confirm` для значимых действий Tauri без нативной проверки.

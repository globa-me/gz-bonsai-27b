# 0.6.1 — переключение модели из чата

Дата: 23 сентября 2026 года.

## Решение

Верхний элемент чата теперь открывает список установленных моделей вместо перехода в каталог. Нажатие на модель запускает её для локального чата. Если уже запущена другая модель, приложение ждёт остановки `llama-server`, затем запускает выбранную модель с её контекстом и vision projector. Текущая модель помечена как запущенная. Там же доступны остановка сервера и переход к управлению загрузками.

Во время генерации ответа, запуска и остановки выбор модели и остановка в меню недоступны. Один процесс `llama-server` обслуживает все чаты и локальный endpoint: переключение меняет модель для последующих запросов, история чатов сохраняется. Если остановка не удалась, новая модель не запускается; ошибка видна в меню и статусе. При ошибке запуска выбранная модель остаётся в настройках для повторной попытки.

Проверенный каталог моделей и встроенный PrismML runtime не менялись. Перед изменениями сверены официальные страницы PrismML на Hugging Face; новая версия не меняет URL, размеры, SHA-256 или лицензии из `docs/verified-artifacts.md`.

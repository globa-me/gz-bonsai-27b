## Оставшееся ограничение проверки

Vision E2E не запускался на этой машине: установленная Bonsai 2 27B PTQ1_0 имеет продуктовую оценку 24 GB RAM, а тестовый Mac — 18 GB. Поддержка projector проверена на уровне каталога, загрузки и формирования аргументов сервера, но качество и расход памяти vision требуют отдельного измерения на подходящей M-series конфигурации. При нативной автоматизации выбирать приложение по полному пути: выбор по имени может открыть старую версию из Applications.

# GZ Bonsai 27B 0.1.0 — preview

Первый публичный предварительный выпуск локального macOS-клиента для PrismML Bonsai.

Что работает:

- нативное определение параметров Mac;
- ручной выбор PrismML `llama-server`, GGUF и необязательного `mmproj`;
- безопасный запуск сервера на `127.0.0.1`;
- потоковый локальный чат;
- русский и английский интерфейс;
- копируемый диагностический отчёт без промптов, секретов и полных путей;
- корректная остановка runtime.

DMG собран для Apple Silicon, подписан Developer ID, нотариально заверен Apple и проверен Gatekeeper.

SHA-256: `b77bf142d555080195a0750c0e4e200c8a23f08143ec8332bac9b07293e9eaa9`

Apple notarization submission: `29093ac8-9afc-4ee8-a13f-e58e8839f9c5` (`Accepted`).

Важно: это preview. Автоматическая загрузка runtime и моделей, рекомендации по памяти и плагины ещё не реализованы. Для запуска чата нужно вручную выбрать совместимый PrismML runtime и GGUF-файл в разделе «Модели».

# GZ Bonsai 27B 0.3.0

## Что изменилось

- основная иконка приложения заменена на выбранный зелёный знак G/Z/B; она встроена в `.app`, DMG и интерфейс;
- добавлены локальная история нескольких чатов и сохранение сообщений в IndexedDB;
- ответы отображаются как безопасный GitHub Flavored Markdown;
- добавлены текстовые, кодовые и графические вложения;
- для трёх 27B-вариантов автоматически скачивается соответствующий проверенный `mmproj`; компактные 1.7B/4B/8B честно отмечены как text-only;
- добавлен включаемый веб-поиск через Bing RSS с явным уведомлением о передаче текста запроса;
- статус модели показывает текущий файл, контекст, фактический RSS процесса, backend и кнопку остановки;
- на экране моделей появился отдельный OpenAI-совместимый endpoint с кнопкой копирования;
- backend подписан как `llama.cpp · Metal · для Apple Silicon` (RU) / `llama.cpp · Metal · for Apple Silicon` (EN), без неверного заявления об MLX.
- ссылки автора, репозитория, Markdown и веб-источников открываются в системном браузере; ссылка автора ведёт на `https://zakharov.asia/ru/`.
- путь к встроенному runtime восстанавливается из текущего app bundle, поэтому перенос приложения из DMG в Applications не оставляет устаревший абсолютный путь.

## Проверка

- `npm test`;
- `npm run build`;
- `cargo test --manifest-path src-tauri/Cargo.toml`;
- нативная подписанная `.app`, проверка `codesign --verify --deep --strict`;
- проверка наличия `CFBundleIconFile` и `Contents/Resources/icon.icns`;
- визуальный запуск release-сборки на macOS.
- Apple notarization, stapling, Gatekeeper и целостность DMG;
- восстановление непустого чата после перезапуска, текстовое вложение и веб-поиск с отображением источников.

## Известные ограничения

- рекомендации RAM и контекста остаются консервативными оценками, пока не собрана измеренная матрица M-series;
- веб-поиск зависит от публичного Bing RSS и не работает без сети;
- историю пока нельзя переименовать или удалить из интерфейса;
- изображения поддерживают только 27B-модели с установленным vision projector.
- vision E2E не измерен на тестовом Mac с 18 GB RAM; для установленной PTQ1_0 приложение консервативно рекомендует 24 GB.

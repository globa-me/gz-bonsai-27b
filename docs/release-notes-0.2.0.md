# GZ Bonsai 27B 0.2.0

Первый полноценно устанавливаемый релиз для macOS на Apple Silicon.

- Подписанное и нотариально заверенное приложение в DMG: перетащите его в Applications.
- Совместимый PrismML `llama-server` уже включён и подписан той же Developer ID подписью.
- Шесть проверяемых загрузок: Bonsai 1.7B, 4B, 8B, бинарная 1-bit Bonsai 27B и ternary Bonsai 2 27B в форматах PTQ1_0 и PQ2_0.
- Автоматическое определение Mac, общей памяти и свободного места; рекомендация модели и контекста явно обозначена как оценка.
- Пауза, HTTP Range resume, отмена, SHA-256, атомарная установка и безопасное удаление моделей.
- Локальный чат, работающий только через `127.0.0.1`, и ручной выбор совместимого GGUF в расширенных настройках.
- Русский и английский интерфейс, безопасный диагностический отчёт и ссылка на сайт автора.
- Новая основная иконка: белый bonsai с буквами G, Z и B в трёх листьях.

Полный пользовательский путь проверен на Apple M3 Pro с Bonsai 1.7B Q1_0. Пороги RAM для более крупных моделей остаются консервативной продуктовой эвристикой до отдельной матрицы измерений.

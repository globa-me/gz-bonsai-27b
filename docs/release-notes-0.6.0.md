# GZ Bonsai 27B 0.6.0

Обновление для macOS на Apple Silicon. Установите DMG перетаскиванием приложения в Applications. Уже скачанные модели и локальная история сохраняются.

## Основные изменения

- Небольшие PDF, DOCX и текстовые документы передаются модели целиком, когда помещаются в контекст. Длинные документы используют выбранные выдержки; один файл показывается как один источник, а цитаты можно раскрыть под ответом.
- Можно остановить ответ и повторить неудачный или прерванный запрос. При ошибке чтения документа запрос не отправляется модели, а текст пользователя остаётся в поле ввода.
- История сохраняет запрос до начала генерации и промежуточный ответ во время неё. После сбоя приложения незавершённый ответ можно повторить; ошибки IndexedDB видны в интерфейсе.
- Первый запуск ведёт к лёгкой подходящей модели. Улучшены подсказки запуска и остановки модели, подписи файлов, работа перетаскивания и удаление локального индекса документа.
- Исправлен SHA-256 файла vision projector `Bonsai-27B-mmproj-Q8_0.gguf` по официальным метаданным PrismML. Это позволяет пройти проверке загрузки projector для соответствующей 27B-модели.
- Добавлен сторожевой процесс для остановки `llama-server`, если приложение аварийно завершилось; длинные циклические ответы прерываются с понятной причиной.

## Проверка и ограничения

Проверка исходников и нативные сценарии описаны в [документе реализации](ux-fixes-2026-09-23.md), проверка подписанного DMG — в [e2e-0.6.0.md](e2e-0.6.0.md). Старые индексы RAG продолжают читаться, но точное исходное форматирование их полного текста не всегда можно восстановить; повторный импорт создаёт новый индекс. OCR для сканированных PDF пока нет. Требования к памяти разных моделей остаются рекомендацией, а не результатом измерений на всех Mac.

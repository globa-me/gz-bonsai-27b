## Что сделано и проверено

Исходный публичный `GZ-Bonsai-27B-0.6.6-arm64.dmg` проверен по SHA-256 `6a07af6c12c2e9f73297d31cb5589a473cff4589462ba44b76310a5b8819e241`. Его копия конвертирована в UDRW и смонтирована; переподписаны 37 Mach-O и app bundle новым SHA-1 с `--options runtime --timestamp`, с сохранением identifier/entitlements/requirements. Затем проверены 38 подписей, issuer OU=G2, точный SHA-1, secure timestamp и единственная архитектура arm64.

Хэши остальных файлов совпадают с исходником (изменён только CodeResources и подписанные Mach-O). Отдельно `otool -s __TEXT __text` подтвердил одинаковый машинный код всех 37 файлов до/после. Встроенный `llama-server --version` после переподписи успешно сообщает `0.2.0-dev`, build `10709`, commit `9a9394a89`, Darwin arm64. Нативный smoke подтвердил запуск из нового DMG, открытие чата и раздела «О приложении», остановленный сервер и версию 0.6.6; приложение после проверки закрыто. Полный UI/inference прогон не повторялся; исторические проверки неизменённого кода сохранены в `e2e-0.6.6.md`.

Приложение упаковано через `ditto -c -k --keepParent` для отдельной нотарификации, после принятия ticket закрепляется через stapler. DMG сохраняет исходную разметку и оформление, конвертируется обратно в UDZO, подписывается G2, отдельно нотарифицируется и stapled. Публичный перевыпуск получает имя `GZ-Bonsai-27B-0.6.6-arm64-G2.dmg`; исторический файл остаётся в релизе.

Первичная отправка ZIP с S3 Transfer Acceleration зависла при загрузке (`ee06c0ec-194d-4b85-a93c-f6fc752e2ec6`); локальный клиент остановлен, повторная отправка с `--no-s3-acceleration` завершила загрузку. Активная заявка приложения: `ce102691-c586-43f6-91a6-50fd5c5c4575`. Использован существующий профиль `GZB-notary`; значения секретов не извлекались.

## Продолжение будущего выпуска

Новый сертификат и старый имеют одинаковое имя. Выбирать по точному SHA-1 выше, а не по имени: для Tauri задавать `APPLE_SIGNING_IDENTITY` этим SHA-1; для ручной подписи `codesign --sign <SHA-1> --options runtime --timestamp`. При следующей пересборке также переподписывать копию встроенного runtime G2 перед подписью app: отслеживаемый исходный runtime не менялся в этой задаче. Проверять issuer OU=G2 у app, DMG и каждого вложенного Mach-O, а также secure timestamp. Ключ доступен в login Keychain для других приложений той же команды; второй G2 получать не требуется.

Публикация: существующий релиз v0.6.6; ссылка README и описание релиза должны вести на G2 DMG. Перед фиксацией успеха скачать именно загруженный asset, сопоставить SHA-256/размер с локальным файлом и GitHub API, проверить Gatekeeper и вложенные подписи. Исторический `e2e-0.6.6.md` не менять задним числом.

## Границы

- В финальном образе проверен запуск уже установленной модели; повторная загрузка GGUF и установка в Applications не проводились, поскольку это затронуло бы текущую пользовательскую установку. Загрузка и pause/resume проверялись в предыдущих релизах, ключевые новые сценарии RAG и истории — в изолированной нативной сборке этого цикла.
- VoiceOver и полнота проверки всех вариантов 27B остаются отдельной задачей. Оценки RAM не являются измеренной матрицей совместимости.

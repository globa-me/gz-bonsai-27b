# E2E-проверка GZ Bonsai 27B 0.5.0

Финальная проверка выполнена 22 сентября 2026 года на Apple M3 Pro, 18 GB unified memory, macOS 26.5. Проверялся именно релизный DMG, а не dev-server.

## Автоматические проверки

- `npm test`: 15 frontend-тестов пройдены;
- `cargo test --locked`: 16 Rust-тестов пройдены;
- `npm run build`: production frontend собран;
- `cargo fmt --check`: пройден;
- `cargo clippy --locked --all-targets -- -D warnings`: пройден;
- `npm audit --omit=dev`: 0 известных уязвимостей.

## Нативный smoke-тест

- из DMG запущена подписанная arm64-сборка и включён bundled PrismML runtime;
- установленная `Bonsai 1.7B Q1_0` прошла health check и streaming chat;
- Tavily Keyless без аккаунта и ключа выполнил реальный русскоязычный поиск о Digital Bridge 2026; модель получила пять релевантных HTTPS-источников, включая официальный `gov.kz`, и показала ссылки в ответе;
- ответ веб-поиска показал `904` токена, `196` выходных токенов, `163,3 ток/с` и `1,8 с`;
- после перезапуска сохранились текст ответа и точные usage/timings, а временные карточки результатов поиска были удалены;
- в списке чатов доступны отдельные действия переименования и удаления.

### Проверка PDF/RAG

Создан реальный трёхстраничный A4 PDF с русским текстовым слоем. До импорта проверены `pdfinfo`, извлечение текста и визуальный рендер всех трёх страниц. Затем файл `gz-bonsai-rag-smoke.pdf` импортирован через системный диалог релизного приложения.

Контрольный вопрос: «Какой код проекта указан в PDF и сколько саженцев участвует в эксперименте?»

Результат:

- RAG нашёл локальный фрагмент и передал его модели как `[D1]`;
- ответ содержал оба точных факта: `BNS-527` и `42`;
- интерфейс показал `529` токенов, `58` выходных токенов, `130,3 ток/с` и `1 с`;
- после полного перезапуска восстановились привязка документа, ответ, ссылка `[D1]` и usage/timings;
- JSON-индекс не содержит исходный абсолютный путь пользователя;
- DOCX extraction дополнительно покрыт Rust unit-тестом на сгенерированном архиве.

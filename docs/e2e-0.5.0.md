# E2E-проверка GZ Bonsai 27B 0.5.0

Документ заполняется по результатам финальной подписанной сборки.

## План проверки

- unit/frontend/build/clippy/security audit;
- arm64 и Developer ID подпись app/runtime;
- Tavily Keyless на реальном русскоязычном запросе и fail-closed ошибка;
- импорт PDF/DOCX/TXT, RAG-поиск и сохранение цитат;
- запуск установленной модели, streaming chat, токены и скорость;
- переименование и удаление чата, восстановление истории после перезапуска;
- Apple notarization, stapling, Gatekeeper и `hdiutil verify`;
- SHA-256 и размер опубликованного DMG.

## Результат

Ожидает финальной сборки.

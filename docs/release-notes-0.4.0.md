# GZ Bonsai 27B 0.4.0

## Что изменилось

- чаты можно переименовывать прямо в боковой панели;
- отдельные чаты можно удалять с подтверждением; при удалении активного чата приложение безопасно выбирает следующий либо создаёт новый;
- каждый завершённый ответ показывает число выходных токенов, среднюю скорость генерации и полное время запроса;
- раскрывающаяся сводка текущего чата показывает число ответов, входные, выходные и общие токены, общее время и взвешенную среднюю скорость;
- значения токенов и скорости берутся из `usage` и `timings` встроенного PrismML llama-server, а не оцениваются по длине текста;
- старые чаты остаются совместимыми: статистика появляется у новых ответов без миграции или потери истории;
- ручное название чата больше не заменяется автоматически первым сообщением.

## Проверка

- `npm test`;
- `npm run build`;
- `cargo fmt --check`;
- `cargo test --locked --manifest-path src-tauri/Cargo.toml`;
- `cargo clippy --locked --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`;
- реальный streaming-запрос к встроенному `prism-b10709-9a9394a` с Bonsai 1.7B подтвердил финальные `usage` и `timings`;
- нативная проверка переименования, сохранения истории и статистики после перезапуска; логика удаления покрыта модульными тестами;
- подписанная и нотариально заверенная arm64-сборка, проверка `codesign`, stapling, Gatekeeper и целостности DMG.

## Известные ограничения

- у старых ответов статистики нет, поскольку предыдущие версии её не сохраняли;
- если поток оборвётся до финального usage-блока, приложение не придумывает число токенов и не показывает неполную метрику;
- выходные токены thinking-моделей могут включать внутренние reasoning-токены, даже если они не показаны в тексте ответа;
- рекомендации RAM и контекста остаются консервативными оценками до расширения измеренной матрицы M-series.

# 0.6.4 — кнопки в каталоге моделей

В карточках каталога нижний ряд действий теперь имеет собственную минимальную высоту: 13px отступа над кнопкой и 36px для кнопки. Это устраняет выход «Скачать» за нижнюю рамку у Bonsai 27B, когда строка «Текст и изображения» переносится на новую строку. Соседние карточки сохраняют одинаковую высоту и нижний отступ.

Браузерный preview каталога теперь отмечает все три 27B-варианта как модели с поддержкой изображений, как и нативный Rust-каталог. URL, размеры и SHA-256 скачиваемых моделей, путь запуска и история чатов не менялись.

Причина: WebKit не всегда включал `min-height` вложенной кнопки в расчёт собственной высоты `.model-actions`. Одного `flex: none` и перестройки карточки на CSS Grid оказалось недостаточно при нативной проверке. Явный `min-height: 49px` исправил карточку в установленном приложении.

Проверки и границы описаны в [e2e-0.6.4.md](e2e-0.6.4.md).

# Нативная проверка 0.6.1

Дата: 23 сентября 2026 года. Устройство: Apple M3 Pro, 18 ГБ unified memory, macOS 26.5.

## Проверено

- `npm test`: 27/27 тестов; `cargo test`: 21/21 тест; `npm run build` и `npm run tauri -- build` успешны.
- Подписанный arm64 app bundle проверен `codesign --verify --deep --strict`. DMG прошёл `hdiutil verify`, Apple Notary Service (submission `d58e5a9b-bb72-495c-9c2c-2e506a1c4b37`, Accepted), `stapler validate` и Gatekeeper `spctl` (`source=Notarized Developer ID`).
- Нативное приложение из DMG показало в селекторе две реально установленные модели: Bonsai 1.7B Q1_0 и Bonsai 2 27B PTQ1_0.
- Выбор Bonsai 1.7B из меню запустил runtime, интерфейс перешёл в «Модель готова».
- Выбор Bonsai 2 27B при работающей 1.7B остановил прежний `llama-server` и запустил новый процесс с PTQ1_0, контекстом 8192 и vision projector. Интерфейс вновь перешёл в «Модель готова»; `GET /health` вернул `{"status":"ok"}`. Запрос к `/v1/chat/completions` вернул `готово` с `finish_reason=stop`.
- Кнопка «Остановить модель» в новом меню завершила сервер и перевела интерфейс в «Сервер остановлен».
- Приложение 0.6.1 установлено в `/Applications/GZ Bonsai 27B.app`; подпись проверена, старый порт 18080 восстановлен. Резервная копия прежнего app bundle сохранена в `~/Library/Application Support/GZ Bonsai Backups/GZ Bonsai 27B 0.6.0.app`.

## Границы

Проверены два уже загруженных варианта на одном Mac. Переключение во время активной генерации защищено состоянием интерфейса, но отдельный нативный E2E с попыткой переключения посреди ответа не проводился. Полная матрица памяти и скорости на разных M-series не измерена. Тестовый запрос к endpoint не записывался в историю чатов.

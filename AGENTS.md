# Инструкции для AI-агентов

## Контекст

Это открытый проект настольного приложения для максимально простого локального запуска моделей Bonsai. Версия `0.6.5` реализована как Tauri 2 + React + TypeScript с Rust-бэкендом. Текущее состояние, проверенные возможности и ограничения описаны в `README.md`; архитектура, разработка, проверенные артефакты и smoke-тест находятся в `docs/`; визуальная система зафиксирована в `DESIGN.md`.

## Продуктовый приоритет

1. macOS на Apple Silicon.
2. Новичок устанавливает приложение и запускает рекомендованную модель без Terminal.
3. Загрузка, запуск, остановка и удаление должны быть надёжными и прозрачными.
4. Локальная приватность и понятный интерфейс важнее количества функций.
5. Endpoint, OpenCode, удалённый доступ и веб-поиск — полезные, но вторичные возможности.
6. Windows и Linux — после стабильного macOS MVP.

## Техническое направление

- Основа проекта: Tauri 2 + React + TypeScript, Rust для системных операций.
- Первый runtime: `llama-server`/`llama.cpp` с Metal и моделями GGUF.
- Не добавлять Python/MLX в основной установочный путь до отдельного подтверждения ценности прототипом.
- Не форкать Jan без нового обоснования: текущая рекомендация — компактная собственная оболочка.
- Большие веса модели никогда не коммитить в Git.
- Сетевой сервер по умолчанию слушает только `127.0.0.1`.

## Правила работы

- Перед изменениями читать актуальную официальную документацию PrismML и проверять, что названия моделей, URL, размеры и лицензии не изменились.
- Не выдавать оценки совместимости и требований к памяти за факт без измерений.
- Не копировать визуальный дизайн ChatGPT или Jan буквально; нужен самостоятельный чистый интерфейс.
- Все пользовательские строки сразу закладывать через локализацию RU/EN.
- Секреты в будущем хранить в Keychain; не писать их в логи или обычные конфиги.
- Загрузки должны поддерживать отмену, возобновление, проверку размера/хэша и безопасное удаление временного файла.
- Управление sidecar должно учитывать аварийное завершение, занятый порт, повторный запуск и восстановление после сна.
- Изменения проверять тестами в соответствии с риском.

## Поддержание контекста

После каждого существенного решения обновлять `README.md` или добавлять документ в `docs/`. Фиксировать:

- что принято и почему;
- что реально проверено;

- известные проблемы и следующий конкретный шаг.

Цель — чтобы другой агент мог продолжить разработку без восстановления истории чата.

## Текущее состояние и следующий шаг

- Релиз `0.6.1` включает подписанный PrismML runtime и каталог из шести файлов: 1.7B/4B/8B Q1_0, отдельную бинарную 1-bit Bonsai 27B и ternary Bonsai 2 27B в PTQ1_0/PQ2_0; URL, размер и SHA-256 закреплены.
- Основная иконка — зелёный квадрат с белым трёхлистным bonsai и буквами G/Z/B в листьях. Редактируемый источник: `src/assets/app-icon.svg`; перед релизом platform icons генерируются `npm run tauri -- icon src/assets/app-icon.svg`.
- Пауза, HTTP Range resume, отмена с очисткой `.part`, атомарная установка и удаление по известному model id реализованы в Rust.
- Полный нативный E2E проверен с Bonsai 1.7B Q1_0: скачивание, SHA-256, Metal, health и streaming chat. Пауза/resume отдельно проверены на загрузке 4B.
- Локальная история поддерживает переименование и удаление чатов. Каждый завершённый ответ сохраняет точные usage/timings из llama-server; UI показывает токены, время, ток/с и сводку по чату.
- Локальный RAG индексирует PDF/DOCX/TXT/Markdown/CSV/JSON в Rust; небольшие документы передаются целиком после проверки `/tokenize`, длинные используют BM25. Интерфейс показывает один файл как один источник. Подробности и границы — `docs/rag.md`.
- В `0.6.0` добавлены Stop/Retry, защита истории при сбоях IndexedDB и аварийном завершении, контроль зависшего `llama-server`, явное удаление локального RAG-индекса и исправленный SHA-256 vision projector. Решения, проверки и известные ограничения — `docs/ux-fixes-2026-09-23.md`, `docs/e2e-0.6.0.md`.
- В `0.6.1` верхний селектор чата запускает и переключает установленные модели, останавливает текущую модель и ведёт в каталог загрузок. Нативная проверка двух моделей, подписанного DMG и ограничений — `docs/e2e-0.6.1.md`.
- В `0.6.2` чат использует компактные кнопки с доступными именами, расширенное поле ввода и скрываемую боковую панель; «Другие модели» заметнее в каталоге. Для веб-поиска Bonsai 2 thinking отключён на уровне запроса к runtime, а параметры генерации разделены по режимам. Проверка и ограничения — `docs/e2e-0.6.2.md`, подробности — `docs/release-notes-0.6.2.md`.
- В `0.6.3` каталог, быстрый старт и селектор установленных моделей показывают исходную Qwen и отдельные ссылки на карточки Bonsai и Qwen в Hugging Face. Provenance хранится в `src-tauri/src/installer.rs`; браузерный preview дублирует его в `src/App.tsx`. При изменении каталога синхронизировать оба места. Проверка — `docs/e2e-0.6.3.md`.
- Исправление `.model-actions` через `min-height: 49px` в `0.6.4` оказалось неполным: пользовательский скриншот установленного приложения показал кнопку Bonsai 27B ниже рамки. В `0.6.5` убраны длинные описания карточек и принудительная высота `.model-card`; размер теперь следует содержимому. Нативно проверены русская и английская локализации при Bonsai 1.7B и PTQ1_0 на Mac; Bonsai 27B расположен рядом с 8B, кнопки внутри рамок. Скрытие боковой панели теперь использует `display: none` вместо нулевой колонки CSS Grid: прежний вариант в нативном WebKit оставлял панель видимой. Детали — `docs/e2e-0.6.5.md`.
- RAM-пороги остаются продуктовой эвристикой, а не доказанной совместимостью; следующий этап — измерения 1-bit/ternary на нескольких M-series и проверка vision на остальных 27B-вариантах.

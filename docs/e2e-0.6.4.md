# Проверка 0.6.4

Дата: 24 сентября 2026 года. Устройство: Apple M3 Pro, 18 ГБ unified memory, macOS 26.5.

## Проверено

- `npm test`: 27/27; `cargo test --locked`: 22/22; `npm run build` и `npm run tauri -- build` успешны.
- В нативном приложении с ранее установленными Bonsai 1.7B и Bonsai 2 27B PTQ1_0 раскрыт каталог. У Bonsai 27B рядом с 8B кнопка «Скачать» теперь находится внутри рамки и имеет такой же нижний отступ, как соседние кнопки. До исправления она выходила за рамку.
- Браузерный макет проверен при ширине 1180px и 920px, с русскими и английскими подписями. При воспроизведённом порядке карточек кнопки не выходят за края; нижний отступ 16px.
- Установленная версия `/Applications/GZ Bonsai 27B.app` показывает `0.6.4`; `codesign --verify --deep --strict` и Gatekeeper `spctl` проходят. Все 36 Mach-O файлов runtime имеют действительные подписи. Предыдущая версия `0.6.3` сохранена в `~/Library/Application Support/GZ Bonsai Backups/GZ Bonsai 27B 0.6.3.app`; история чатов осталась на месте.
- Финальный arm64 DMG прошёл `hdiutil verify`, Apple Notary Service (submission `6015e075-0a30-4ae5-b319-4cb412749a1a`, Accepted), `stapler validate` и Gatekeeper `spctl` (`source=Notarized Developer ID`). Размер: 30 558 384 байта; SHA-256: `e2ba5ea1e7fcd3b32c7cee831427f721938d89200b69bde0276487407323fd11`.

## Границы и продолжение

Изменение затронуло только CSS каталога и браузерный preview возможностей 27B. Загрузка весов и генерация ответов повторно не выполнялись; соответствующие пути проверены в предыдущих релизах. Следующий шаг продукта остаётся прежним: измерить 1-bit и ternary 27B на нескольких M-series и проверить vision для остальных 27B-вариантов.

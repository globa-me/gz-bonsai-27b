# 0.6.5 — карточки моделей и меньше текста

В установленной 0.6.4 кнопка «Скачать» у Bonsai 27B оставалась ниже рамки карточки. У `.model-card` убрана принудительная минимальная высота, а у `.model-actions` — попытка компенсировать её минимальной высотой. Карточка теперь растёт вместе с содержимым; одинаковые строки каталога сохраняют общий нижний край и отступ под кнопками.

Из каталога убраны длинные повторяющиеся описания моделей. Название, исходная Qwen, ссылки на обе модели в Hugging Face, размер, приблизительная оценка памяти, контекст и поддержка изображений остались. Быстрый старт и API-блок стали короче; на странице диагностики сокращены пояснения без удаления предупреждения о передаче поисковых запросов и хранении Brave-ключа в Keychain. Строки обновлены для RU и EN.

Нативная проверка также обнаружила, что кнопка скрытия боковой панели меняла состояние, но WebKit оставлял панель видимой. Скрытие теперь убирает панель из CSS Grid и DOM-раскладки (`display: none`); свободное место сразу отдаётся основному экрану.

Проблема была связана с высотой карточки при переносе характеристик, а не с устаревшей установленной версией. Проверка браузерного макета без нативного WebKit была недостаточной. Дальнейшие изменения каталога следует сверять в установленном приложении с Bonsai 27B рядом с 8B и выбранной PTQ1_0. Проверки и границы — [e2e-0.6.5.md](e2e-0.6.5.md).

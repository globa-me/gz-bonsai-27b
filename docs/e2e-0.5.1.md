# E2E-проверка GZ Bonsai 27B 0.5.1

Дата проверки: 22 сентября 2026 года. Устройство: Apple M3 Pro, macOS 26.5, `aarch64`.

## Что проверено

- `npm test`: 7 файлов, 19 тестов; отдельно покрыты маршрутизация dropped PDF/DOCX в RAG, обычных файлов во вложения и восстановление автоназваний чатов;
- `npm run build`, `npm audit --omit=dev`, `cargo fmt --check`, `cargo test --locked` (16 тестов) и `cargo clippy --all-targets -- -D warnings` прошли;
- финальный DMG смонтирован, приложение запущено непосредственно с образа;
- визуально проверены 13 px заголовки недавних чатов, восстановление старых автоназваний из первого сообщения и отсутствие постоянного резервирования места под скрытые действия; финальный вариант сохраняет одну строку на всю ширину сайдбара;
- Bonsai 1.7B Q1_0 запущена из релизной сборки на отдельном порту `18080`; health вернул `ok`, два потоковых ответа завершились с точной статистикой (в длинном ответе: 498 выходных токенов, 136,9 ток/с, 3,7 с);
- состояние подготовки ответа заменено компонентом с тремя анимированными точками; при Reduce Motion анимация отключается;
- обработчик системного Tauri drag-and-drop зарегистрирован в релизной сборке; при переносе пользовательского PDF из Finder релизная сборка показала зону «Отпустите файлы, чтобы добавить». PDF/DOCX направляются в локальный RAG, остальные поддержанные файлы — во вложения запроса; маршрутизация покрыта unit-тестом. Средство UI-автоматизации macOS не смогло надёжно завершить межоконное отпускание мыши, поэтому финальный результат самого drop остаётся коротким ручным smoke-тестом после установки;
- пользовательский PDF `Резюме Геннадий Захаров, обновленное 2026, RUS.pdf`: 2 страницы A4, 2 732 586 байт, без шифрования; обе страницы отрендерены и визуально проверены без дефектов. Существующий локальный индекс содержит 4 перекрывающихся текстовых фрагмента длиной 1395, 1386, 1395 и 1311 символов;
- prompt RAG сохраняет защиту от инструкций внутри документов, но теперь явно запрещает выводить пользователю техническую формулировку о «недоверенных данных».
